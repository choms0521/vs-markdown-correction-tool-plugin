P4 — 제출 흐름 (Submit Flow)

Phase 4 detailed plan · PromptBuilder + ProviderConfig + LLMOrchestrator + ResponseExtractor · 마스터 계획 docs/plans/vscode-md-review-plan.md 분해본 · 2026-05-15 작성

1. 개요

본 phase는 P3 [제출] 버튼이 발화하는 submit 메시지를 실제 LLM 호출까지 연결한다. PromptBuilder가 envelope/sentinel을 포함한 단일 prompt를 조립하고, ProviderConfig가 두 가지 화이트리스트(args 토큰 + command basename)로 cost driver 위반을 차단하며, LLMOrchestrator가 NodePtySession + TerminationDetector + ResponseExtractor를 연결하여 응답 마크다운을 추출한다. P5 diff 적용 전 단계까지 완성한다.

Goalenvelope/sentinel 포맷 prompt 송신 → interactive CLI 응답 수신 → fenced markdown 추출까지 단일 흐름 완성. 화이트리스트 이중 검증으로 비용 driver 위반 차단. P3 [제출] 버튼이 LLMOrchestrator로 routing.

2. RALPLAN-DR 요약

2.1 Principles (4)

  1. Single prompt envelope — host는 항상 <<<BEGIN-{uuid}>>> ~ <<<END-{uuid}>>> 사이에 prompt를 감싸 송신한다. uuid는 매 호출마다 재생성하여 R-15 (본문 우연 충돌) 1차 방어. TerminationDetector가 Stage A에서 PROMPT_END 후 buffer만 응답으로 처리.
  2. Deny-by-default 화이트리스트 — args/command 모두 명시적으로 허용된 값만 통과. -p/--print은 cost-guard lint에서도 거부되지만, runtime spawn에서도 다시 거부 (defense in depth). 잘못된 settings에 대해 silent 동작 금지.
  3. Detector는 provider별 격리 — DetectorStrategy 패턴(P1에서 도입)을 그대로 활용. claude/codex/gemini별 submit key 차이와 shell prompt 정규식 차이를 strategy 안에 캡슐화. orchestrator는 strategy를 통해 추상화된 인터페이스로만 의존.
  4. Response는 fenced 우선, 폴백은 trim — LLM이 ```markdown ... ```로 감싸 출력하도록 prompt에서 요청. ResponseExtractor가 1순위로 fenced block을 잡고, 없으면 sentinel trim 영역을 그대로 반환. 모호한 휴리스틱 추가 금지.

2.2 Decision Drivers (Top 3)

#Driver설명
D1비용 driver 위반 차단 (R-7)claude -p는 종량 과금. 사용자가 settings 오설정으로도 절대 spawn 안 되어야 함. 이중 화이트리스트 + lint + runtime guard로 3중 방어.
D2응답 종료 deterministic 결정LLM이 sentinel을 누락해도 shell prompt 복귀(Stage B2) + 90s timeout(Stage B3)으로 반드시 종료. orchestrator는 settled 결과만 ResponseExtractor에 전달.
D3provider 교체 비용 최소화settings의 defaultProvider 변경만으로 host 측 코드 수정 없이 다른 provider 사용. DetectorStrategy + ProviderConfig가 provider별 차이를 흡수.

2.3 Viable Options (≥2 비교)

옵션설명ProsCons
A. envelope + sentinel + shell prompt 3단 detector 선택 P1에서 확립한 TerminationDetector 그대로 활용. PromptBuilder가 envelope/sentinel 토큰을 생성하고 orchestrator가 wiring. P1 회귀 자산 reuse, deterministic 종료 보장, R-11/R-13/R-15/R-16 완화 이미 검증됨 prompt가 다소 verbose (envelope + sentinel 지시문)
B. sentinel만 단일 detectorenvelope 없이 sentinel만 매칭.prompt 단순PTY echo back으로 false-resolve (R-11), 마스터 plan에서 이미 기각
C. WebSocket-based LLM APIOpenAI/Anthropic 직접 호출.응답 종료 명확본 프로젝트 핵심 동인(인터랙티브 모드 활용으로 과금 회피)과 정면 충돌

2.4 선택 근거

Primary: A (envelope + sentinel + shell prompt) P1 PTY 코어가 이미 envelope-aware로 구현되어 있고 6가지 echo 케이스 회귀 테스트가 있다. 본 phase는 P1 자산을 PromptBuilder에서 envelope 토큰 생성 + LLMOrchestrator에서 detector wiring으로 활용하기만 하면 된다. B는 이미 마스터 plan에서 기각된 옵션 — silent bug 위험. C는 본 프로젝트 핵심 동인 위반이라 즉시 기각.

    <<<BEGIN-{uuid}>>>
다음 마크다운 본문을 코멘트에 따라 수정해 주십시오.
응답은 ```markdown 으로 감싼 fenced block 하나로만 보내십시오.

--- 코멘트 ---

  • uuid 정책: build가 uuid를 argument로 받는다 (DI). 인자가 없으면 randomUUID()로 생성. 테스트에서는 명시 주입하여 결정성 확보.

  • ALLOWED_ARGS: 현재 phase에서는 세 provider 모두 빈 set. 즉 어떤 추가 args도 거부. 향후 P5/P6에서 필요 시 명시적으로 추가.
  • ALLOWED_COMMAND_BASENAMES: { claude: 'claude', codex: 'codex', gemini: 'gemini' }. command 값에 /가 포함되면 마지막 segment를 basename으로 비교.
  • validateCommand 로그 형식: 성공 시에도 [cost-guard] resolved-command=<raw> basename=<basename> 1줄 로그. 실패 시 한국어 에러 throw + 별도 로그 라인.
  • ResponseExtractor 정규식: /```(?:markdown|md)?\n([\s\S]*?)\n```/. 첫 매치만 사용. 매칭 실패 시 raw trim.
  • ResponseExtractor 강화 (NEW): thinking 블록(<thinking> ... </thinking>)이 응답에 포함된 경우 fenced 추출이 우선이므로 자연스럽게 배제됨. 폴백 경로에서 thinking 태그 제거는 본 phase 범위 외 (모호한 휴리스틱 도입 금지 원칙).

5.1 src/llm/PromptBuilder.ts

import { randomUUID } from 'crypto';
import { type Comment } from '../model/Comment';

export interface BuiltPrompt {
  prompt: string;
  envelopeBegin: string;
  envelopeEnd: string;
  sentinel: string;
  uuid: string;
}

export class PromptBuilder {
  build(documentText: string, comments: readonly Comment[], uuid?: string): BuiltPrompt {
    const id = uuid ?? randomUUID();
    const envelopeBegin = `<<<BEGIN-${id}>>>`;
    const envelopeEnd = `<<<END-${id}>>>`;
    const sentinel = `<<<DONE-${id}>>>`;
    const joined = this.joinComments(comments);

    const body = [
      envelopeBegin,
      '다음 마크다운 본문을 코멘트에 따라 수정해 주십시오.',
      '응답은 ```markdown 으로 감싼 fenced block 하나로만 보내십시오.',
      `응답 마지막에 정확히 다음 한 줄을 출력하십시오: ${sentinel}`,
      '',
      '--- 본문 ---',
      documentText,
      '',
      '--- 코멘트 ---',
      joined.length > 0 ? joined : '(코멘트 없음)',
      envelopeEnd,
    ].join('\n');

    return { prompt: body, envelopeBegin, envelopeEnd, sentinel, uuid: id };
  }

  private joinComments(comments: readonly Comment[]): string {
    const lines: string[] = [];
    let index = 1;
    for (const c of comments) {
      if (c.type === 'suggestion') {
        const before = c.before ?? '';
        const after = c.after ?? '';
        if (before.length === 0 && after.length === 0) continue;
        lines.push(`[${index}] (suggestion) line ${c.anchor.line}, col ${c.anchor.col}: "${before}" → "${after}"${c.note ? ` : ${c.note}` : ''}`);
      } else {
        const note = (c.note ?? '').trim();
        if (note.length === 0) continue;
        lines.push(`[${index}] (question) line ${c.anchor.line}, col ${c.anchor.col}: ${note}`);
      }
      index += 1;
    }
    return lines.join('\n');
  }
}

5.2 src/llm/ProviderConfig.ts

import { z } from 'zod';

export const ProviderNameSchema = z.enum(['claude', 'codex', 'gemini']);
export type ProviderName = z.infer<typeof ProviderNameSchema>;

export const ProviderConfigSchema = z.object({
  command: z.string().regex(
    /^(?:.*\/)?(?:claude|codex|gemini)$/,
    'command basename must be exactly one of claude/codex/gemini',
  ),
  args: z.array(z.string()).default([]),
  cwd: z.string().optional(),
  env: z.record(z.string()).optional(),
});
export type ProviderConfig = z.infer<typeof ProviderConfigSchema>;

export const ALLOWED_ARGS: Readonly<Record<ProviderName, ReadonlySet<string>>> = {
  claude: new Set(),
  codex:  new Set(),
  gemini: new Set(),
};

export const ALLOWED_COMMAND_BASENAMES: Readonly<Record<ProviderName, string>> = {
  claude: 'claude', codex: 'codex', gemini: 'gemini',
};

export function commandBasename(command: string): string {
  const trimmed = command.trim();
  const idx = trimmed.lastIndexOf('/');
  return idx >= 0 ? trimmed.slice(idx + 1) : trimmed;
}

export interface CostGuardOutput {
  appendLine(line: string): void;
}

export function validateCommand(
  provider: ProviderName,
  command: string,
  output?: CostGuardOutput,
): void {
  const basename = commandBasename(command);
  const expected = ALLOWED_COMMAND_BASENAMES[provider];
  output?.appendLine(`[cost-guard] resolved-command=${command} basename=${basename}`);
  if (basename !== expected) {
    throw new Error(
      `[cost-guard] provider '${provider}'의 command basename은 '${expected}'만 허용됨. ` +
      `현재: '${basename}'. wrapper script로 우회하는 것은 비용 driver 위반 위험이라 차단합니다.`,
    );
  }
}

export function validateArgs(
  provider: ProviderName,
  args: readonly string[],
  output?: CostGuardOutput,
): void {
  const allowed = ALLOWED_ARGS[provider];
  const violating = args.filter((a) => !allowed.has(a));
  if (violating.length > 0) {
    output?.appendLine(
      `[cost-guard] event=args-whitelist-violation provider=${provider} violating=${violating.join(',')}`,
    );
    throw new Error(
      `[cost-guard] provider '${provider}'에 허용되지 않은 args 발견: ${violating.join(', ')}. ` +
      `종량 과금 위험으로 spawn을 거부합니다.`,
    );
  }
}

export class ResponseExtractor {
  extract(raw: string): string {
    // fenced markdown 우선. 첫 fence만 사용 — 다중 fence 휴리스틱 도입 금지.
    const match = raw.match(/```(?:markdown|md)?\n([\s\S]*?)\n```/);
    if (match) return match[1].trim();
    return raw.trim();
  }
}

5.4 src/llm/LLMOrchestrator.ts

import { type Comment } from '../model/Comment';
import { PromptBuilder, type BuiltPrompt } from './PromptBuilder';
import { ResponseExtractor } from './ResponseExtractor';
import {
  validateCommand, validateArgs,
  type ProviderName, type CostGuardOutput,
} from './ProviderConfig';
import { TerminationDetector } from '../pty/TerminationDetector';
import { DetectorFactory } from '../pty/detector/DetectorFactory';

export interface PtySessionLike {
  write(payload: string): void;
  onData(handler: (chunk: string) => void): { dispose(): void };
  kill(signal?: 'SIGTERM' | 'SIGKILL', forceTimeoutMs?: number): Promise<void>;
}

export interface LLMOrchestratorDeps {
  readConfig(): { provider: ProviderName; command: string; args: string[]; sentinelTimeoutMs: number };
  spawn(command: string, args: string[]): PtySessionLike;
  output: CostGuardOutput;
  promptBuilder?: PromptBuilder;
  responseExtractor?: ResponseExtractor;
}

export interface SubmitResult {
  markdown: string;
  raw: string;
  uuid: string;
}

export class LLMOrchestrator {
  private readonly promptBuilder: PromptBuilder;
  private readonly responseExtractor: ResponseExtractor;

  constructor(private readonly deps: LLMOrchestratorDeps) {
    this.promptBuilder = deps.promptBuilder ?? new PromptBuilder();
    this.responseExtractor = deps.responseExtractor ?? new ResponseExtractor();
  }

  async submit(documentText: string, comments: readonly Comment[]): Promise<SubmitResult> {
    const cfg = this.deps.readConfig();
    validateCommand(cfg.provider, cfg.command, this.deps.output);
    validateArgs(cfg.provider, cfg.args, this.deps.output);

    const built: BuiltPrompt = this.promptBuilder.build(documentText, comments);
    const strategy = DetectorFactory.for(cfg.provider);
    const session = this.deps.spawn(cfg.command, cfg.args);

    try {
      const raw = await new Promise<string>((resolve, reject) => {
        const detector = new TerminationDetector({
          envelopeEnd: built.envelopeEnd,
          sentinel: built.sentinel,
          shellPromptRegex: strategy.shellPromptRegex,
          hardTimeoutMs: cfg.sentinelTimeoutMs,
        }, (body) => { resolve(body); }, (err) => { reject(err); });

        const sub = session.onData((chunk) => detector.feed(chunk));
        const tail = strategy.submitKey === '\r\n' ? '\r\n' : '\r';
        session.write(built.prompt + tail);
        // detector resolve/reject 시 settle 보장 — sub.dispose는 finally에서 처리.
        void sub;
      });
      return { markdown: this.responseExtractor.extract(raw), raw, uuid: built.uuid };
    } finally {
      await session.kill('SIGTERM');
    }
  }
}
